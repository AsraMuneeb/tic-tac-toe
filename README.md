🎮 Tic-Tac-Toe Game
Welcome to my Tic-Tac-Toe project! This is my first React-based project, developed during my summer vacation to sharpen my front-end development skills. It uses React, JavaScript, HTML, and CSS to create a fully interactive, responsive game.

🚀 Key Features
🔄 Player Turn Management: Uses React's useState hook to alternate turns between players smoothly.
📊 Dynamic Game Board State: Tracks and updates the board's state in real-time with React, allowing players to interact without page refresh.
🏆 Win Detection Logic: Implements custom JavaScript logic to detect winning combinations or ties, providing immediate feedback.
🔁 Reset Game: A simple reset button allows the board to refresh without the need for a page reload.
📱 Responsive Design: The game is fully responsive, providing a seamless experience across all screen sizes, from mobile to desktop.

🛠️ Technologies Used
React: For building reusable UI components and handling the game logic.
JavaScript (ES6): For creating the game logic and managing state.
HTML5: For structuring the layout of the game.
CSS3: For creating a responsive, visually appealing design.

⚙️ How to Run the Project

Clone the repository:
git clone https://github.com/your-username/tic-tac-toe.git

Install the dependencies:
npm install

Start the development server:
npm start

The game will open in your browser 

🎮 Game Rules
Players alternate turns, placing their mark (X or O) on the board.
The first player to get three marks in a row (horizontally, vertically, or diagonally) wins the game.
If the board fills up without a winner, the game ends in a draw.
Click the "Reset" button to start a new game.
