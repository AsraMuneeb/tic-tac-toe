The main difference lies in how they store data. Primitives store the actual value directly, 
making them memory-efficient and faster to access i.e. ('asra', 28, true) becuase they cannot be change or eidited but they can redefine
Reference types store memory addresses, enabling them to reference complex objects and share data across different program parts

ARROW FUNCTIONS
Arrow functions are a different way of creating functions in JavaScript. Besides a shorter syntax, they offer 
advantages when it comes to keeping the scope of the this  keyword.

function callMe(name) { 
    console.log(name);
}
which you could also write as:

const callMe = function(name) { 
    console.log(name);
}
becomes: 

const callMe = (name) => { 
    console.log(name);
}
